## 核心理念

「静-悦-扩」是一套源自个人体证，融合了阳明心学、禅宗与现代认知科学的内在决策与伦理评估框架。它旨在为个人及人工智能系统，提供一个实时的、基于第一人称体验的“起心动念”检验工具。

- **【静 (Stillness)】:** 该决策是否让我的内在系统更趋于**宁静**，而非**焦躁**？
- **【悦 (Joyfulness)】:** 该决策是否让我的生命力更趋于**舒展**，而非**萎缩**？
- **【扩 (Expansion)】:** 该决策是否让我与自己、与他人、与世界的连接更趋于**开阔**，而非**狭隘**？
